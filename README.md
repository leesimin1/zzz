# (앱 이름) POLAR HOME

프로젝트를 시작하기 전에 [docs/SETUP.md](docs/SETUP.md)를 먼저 읽으세요.

## 프로젝트 개요
- 한 줄 소개:자신이 사용한 전력 내역을 한 눈에 정리해 보여주고, 에너지 절약을 돕는 프로그램
- 누구를 위한 앱인가:전기세를 절약하고자 하는 사람
- 어떤 상황에서 쓰는가:당월 사용한 전력량과 전기 요금이 얼마인지 궁금할 때, 에너지를 아끼는 방법으로 무엇이 있는지 궁금할 때

## 주요 기능
| 과제의 꼭 있어야 하는 기능 | 화면(프론트엔드) | API(백엔드) |
| --- | --- | --- |
| 1. 시간대별 발전, 사용 전력 한 눈에 보기| 그래프로 사용자 본인의 환경에 맞춰 조정할 수 있음 | 요금제는 비피크, 중간, 피크를 기본 단가로 계산. 실시간 모드에서는 시간에 따른 변동을 합산해 계산 |
| 2. 이번달 예상 요금 표시| 마이페이지 및 홈 대시보드 | 누적 집계, 남은 기간 예측, 데이터 저장과 갱신, 예상 금액이 설정한 금액을 초과 시 피드백 |
| 3. 절약 실천 과제| 미션을 완수함으로서 보상 획득 및 레벨 상승, 에너지 절약 보조 | 미션은 무작위로 정해짐, 완수한 미션으로 절감한 탄소량을 계산하여 합산 표시 |

더 만든 기능: 에너지 절약 퀴즈

## 기술 스택
- 프론트엔드:HTML 5, Nest.js
- 백엔드:Node.js
- 데이터(어디에, 무엇을): 데이터베이스에 개인 정보 저장, 그래프 페이지 - 월별 요금 트렌드 및 기기별 사용량 비중, 마이 페이지 - 퀴즈 데이터 및 사용자의 개인 사용량

## 팀원 역할
