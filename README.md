# (앱 이름) POLAR HOME

프로젝트를 시작하기 전에 [docs/SETUP.md](docs/SETUP.md)를 먼저 읽으세요.

## 프로젝트 개요
- 한 줄 소개: 우리 집 전력 사용량과 예상 전기요금을 확인하고, 미션과 북극곰 키우기를 통해 에너지 절약을 실천하는 웹앱
- 누구를 위한 앱인가: 전기요금을 줄이고 싶거나 에너지 절약 습관을 만들고 싶은 사람
- 어떤 상황에서 쓰는가: 이번 달 전력 사용량과 예상 요금이 궁금할 때, 가전기기별 사용량을 비교하고 싶을 때, 에너지 절약 방법을 알고 싶을 때

## 주요 기능
| 과제의 꼭 있어야 하는 기능 | 화면(프론트엔드) | API(백엔드) |
| --- | --- | --- |
| 1. 시간대별 발전, 사용 전력 확인| 발전원과 가전기기를 추가하거나 켜고 끄면서 그래프 변화를 확인할 수 있음. 발전원 출력·사용 시간·일사량·풍량 조절 가능 | 요금제는 비피크, 중간, 피크를 기본 단가로 브라우저에서 계산을 처리. 실제 전력 조회 API는 연결하지 않음 |
| 2. 이번 달 사용량, 예상 요금 표시| 메인·마이페이지·그래프에서 같은 사용량을 표시하고, 절약 목표에 따라 북극곰 표정이 달라짐 | 로그인한 사용자의 이름·주소를 조회·수정하는 API 제공. 사용량과 예상 요금은 주소·가전 설정을 바탕으로 데모 계산 |
| 3. 절약 실천 과제| 무작위 절약 미션, 완료 보상, 먹이 주기, 북극곰 성장, 활동 기록과 배지 수집 제공 | 현재 미션 진행 상황과 보상은 브라우저에서 처리하고 계정별 localStorage에 저장 |

더 만든 기능: 에너지 절약 퀴즈 - 총 60문제의 문제 은행 / 회원가입·로그인 - Supabase Auth를 사용해 다른 기기에서도 같은 계정으로 로그인 / 내 정보 수정 - 이름과 집주소를 저장·수정하고, 주소 변경 시 데모 사용량과 예상 요금에 반영 / 북극곰 상호작용 - 먹이 주기, 성장 단계별 모습, 클릭 반응, 마지막 먹이 지급 후 12시간이 지나면 배고픔 상태 표시 / FAQ - 화면 구석의 고정 버튼을 통해 절약·미션·서비스 이용 방법 안내

## 기술 스택
- 프론트엔드: Next.js App Router, React, TypeScript, HTML5, CSS, Tailwind CSS, Chart.js
- 백엔드: Node.js 환경의 Next.js Route Handler
- 데이터(어디에, 무엇을): Supabase - 회원 계정, 이름, 집주소 / 계정별 localStorage - 미션·북극곰 진행 상황, 가전기기 설정, 일부 퀴즈 진행 기록 / 브라우저 계산 - 주소 기반 데모 사용량, 예상 전기요금, 발전량·소비량 그래프

## AI 활용 내역
- 사용한 도구: CHATGPT, Codex, Claude
- 주요 프롬프트(그대로 붙여 넣기):
  - "메인페이지에서 아래에 챗봇을 넣어서 궁금한걸 풀수있게 해줘"
  - “집주소가 변경되면 전기요금도 변경될수있게 변경해줘”
  - “마이페이지에 있는 퀴즈맞추면 폭죽 터트려줘”
- AI가 만든 것 / 사람이 고친 것: 화면 코드 초안, 페이지 통합 코드, 인증 연동, 데모 사용량·요금 계산, 미션·퀴즈 로직, 북극곰 애니메이션과 오류 수정 코드 / 서비스 목적, 페이지별 역할 분담, 디자인 참고 자료, 원하는 사용자 흐름, 기능 개선 방향과 실제 이용 결과
- 결과를 확인한 방법: 브라우저에서 주요 기능을 직접 사용, 모바일 크기의 화면 배치와 계정·주소별 데이터 변화 확인. 타입·린트·빌드 검사와 배포 후 공개 URL 확인 진행.

## 팀원 역할
(이름·학번 없이 역할만)
- 기획: 서비스 콘셉트, 사용자 이용 흐름, 절약 목표·미션·퀴즈 구성 기획
- 프론트엔드: 메인, 로그인·회원가입, 마이페이지, 미션, 그래프 화면을 나누어 구현하고 공통 디자인과 페이지 이동 통합
- 백엔드: Supabase 인증 연결, 회원가입·로그인·로그아웃·내 정보 수정 API 구현, 계정 정보 저장과 입력 검증
- 검증: 기능별 동작 확인, 계정별 데이터 구분 확인, 모바일 화면 점검, 오류 재현과 수정, 배포 주소 및 발표 시연 흐름 확인

## 아쉬운 점과 다음에 할 일
- 실제 전력 데이터 연동 : 부족 현재는 주소 기반 데모 데이터를 사용한다. 앞으로 한전 등 실제 전력 데이터와 연동해 우리 집 사용량을 확인하도록 개선하고 싶다.
- 기기 간 활동 기록 공유 부족 : 일부 활동 기록과 설정이 브라우저에만 저장된다. 서버 저장을 도입해 다른 기기에서도 이어서 사용할 수 있도록 개선하고 싶다.
- 요금 예측의 한계 : 현재 예상 요금은 실제 청구 금액과 차이가 날 수 있다. 계절·요금제·사용 패턴을 반영해 예측 정확도를 높이고 싶다.
- 미션 효과 검증 부족 : 미션 완료는 사용자의 직접 확인에 의존한다. 실제 사용량 변화와 연결해 절약 효과를 보여주고 싶다.
- 서비스 확장 : FAQ 챗봇의 질문 범위를 늘리고, 가정별 사용 패턴에 맞춘 절약 방법을 안내하고 싶다.
