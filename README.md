# (앱 이름) POLAR HOME

프로젝트를 시작하기 전에 [docs/SETUP.md](docs/SETUP.md)를 먼저 읽으세요.

## 프로젝트 개요
- 한 줄 소개:우리 집 전력 사용량과 예상 전기요금을 확인하고, 미션과 북극곰 키우기를 통해 에너지 절약을 실천하는 웹앱
- 누구를 위한 앱인가:전기요금을 줄이고 싶거나 에너지 절약 습관을 만들고 싶은 사람
- 어떤 상황에서 쓰는가:이번 달 전력 사용량과 예상 요금이 궁금할 때, 가전기기별 사용량을 비교하고 싶을 때, 에너지 절약 방법을 알고 싶을 때

## 주요 기능
| 과제의 꼭 있어야 하는 기능 | 화면(프론트엔드) | API(백엔드) |
| --- | --- | --- |
| 1. 시간대별 발전, 사용 전력 확인| 발전원과 가전기기를 추가하거나 켜고 끄면서 그래프 변화를 확인할 수 있음. 발전원 출력·사용 시간·일사량·풍량 조절 가능 | 요금제는 비피크, 중간, 피크를 기본 단가로 브라우저에서 계산을 처리. 실제 전력 조회 API는 연결하지 않음 |
| 2. 이번 달 사용량, 예상 요금 표시| 메인·마이페이지·그래프에서 같은 사용량을 표시하고, 절약 목표에 따라 북극곰 표정이 달라짐 | 로그인한 사용자의 이름·주소를 조회·수정하는 API 제공. 사용량과 예상 요금은 주소·가전 설정을 바탕으로 데모 계산 |
| 3. 절약 실천 과제| 무작위 절약 미션, 완료 보상, 먹이 주기, 북극곰 성장, 활동 기록과 배지 수집 제공 | 현재 미션 진행 상황과 보상은 브라우저에서 처리하고 계정별 localStorage에 저장 |

더 만든 기능: 에너지 절약 퀴즈 - 총 60문제의 문제 은행
회원가입·로그인 - Supabase Auth를 사용해 다른 기기에서도 같은 계정으로 로그인
내 정보 수정 - 이름과 집주소를 저장·수정하고, 주소 변경 시 데모 사용량과 예상 요금에 반영
북극곰 상호작용 - 먹이 주기, 성장 단계별 모습, 클릭 반응, 마지막 먹이 지급 후 12시간이 지나면 배고픔 상태 표시

## 기술 스택
- 프론트엔드:HTML 5, Nest.js
- 백엔드:Node.js
- 데이터(어디에, 무엇을): 데이터베이스에 개인 정보 저장, 그래프 페이지 - 월별 요금 트렌드 및 기기별 사용량 비중, 마이 페이지 - 퀴즈 데이터 및 사용자의 개인 사용량
